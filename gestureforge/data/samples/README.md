# Sample Gesture Data

Place your sample gesture images and videos in this directory.

## Supported Formats

### Images
- JPG, JPEG
- PNG
- BMP

### Videos
- MP4
- AVI
- MOV
- MKV

## Usage

These files can be used to test the GestureForge v2 system without needing to create your own gesture samples.

Simply upload them through the Streamlit interface.
