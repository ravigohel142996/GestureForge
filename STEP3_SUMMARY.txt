================================================================================
KEY IMPLEMENTATION DECISIONS
================================================================================

1. WHY RANDOMFOREST?
   ✅ Fast inference (<5ms per frame)
   ✅ No GPU required (runs on any CPU)
   ✅ Robust to outliers (ensemble approach)
   ✅ Explainable (feature importance)
   ✅ Small data friendly (hundreds, not thousands)
   ✅ Confidence scores (voting mechanism)

2. CONFIDENCE COMPUTATION
   - Uses voting from ensemble of trees
   - Confidence = proportion of trees voting for predicted class
   - Example: 85/100 trees vote "pinch" → confidence = 0.85
   - Threshold (>0.7) filters uncertain predictions
   - Prevents false positives in real-time control

3. REAL-TIME USAGE PATTERN
   Startup (once):
     clf = GestureClassifier()
     clf.load_model('gesture_model.pkl')
   
   Per frame (30fps):
     result = clf.predict_gesture(landmarks)
     if result['confidence'] > 0.7:
         execute_action(result['gesture'])

================================================================================
TECHNICAL SPECIFICATIONS
================================================================================

Model Architecture:
  - Input: 63-dimensional vector (21 landmarks × 3 coordinates)
  - Algorithm: RandomForestClassifier
  - n_estimators: 100 trees (default)
  - max_depth: 20 levels (default)
  - min_samples_split: 5 (default)
  - class_weight: balanced
  - Output: {gesture, confidence, all_probabilities}

Feature Importance (typical):
  1. landmark_12_y (middle finger tip Y-axis) - Most important
  2. landmark_8_y (index finger tip Y-axis)
  3. landmark_4_y (thumb tip Y-axis)
  4. landmark_16_y (ring finger tip Y-axis)
  5. landmark_8_z (index finger tip depth)
  → Finger tip positions are most discriminative!

Supported Gestures:
  1. open_palm - All fingers extended
  2. pinch - Thumb and index close together
  3. swipe - Hand tilted/rotated
  4. fist - All fingers curled
  5. rotate - Intermediate positions with rotation
